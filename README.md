# 🚢 Cruise Price Prediction

## Project Overview

This project focuses on developing a Machine Learning model to predict cruise ticket prices based on trip characteristics and company-related features.

The project covers the complete Data Science workflow, from data collection and preprocessing to exploratory data analysis, feature engineering, model development, and visualization of results.

## 🎯 Project Objectives

- Collect and analyze cruise-related data.
- Identify factors influencing cruise ticket prices.
- Perform data cleaning and exploratory data analysis.
- Engineer meaningful features for Machine Learning.
- Develop and evaluate regression models.
- Present findings through data visualizations and a dashboard.

## 🛠️ Technologies Used

- Python
- Pandas & NumPy
- Matplotlib & Seaborn
- BeautifulSoup & Requests
- Scikit-learn
- XGBoost
- Tableau

## 📊 Model Performance

The Random Forest regression model achieved the following results:

| Metric | Score |
|---|---:|
| Training R² | 0.9156 |
| Testing R² | 0.9192 |

The model achieved a test R² score of 0.9192 on the log-transformed target variable.

## 🔍 Project Workflow

1. **Data Collection:** Web scraping using Requests and BeautifulSoup.
2. **Data Preprocessing:** Handling missing values, duplicates, and data inconsistencies.
3. **Exploratory Data Analysis:** Investigating cruise pricing patterns and relationships.
4. **Feature Engineering:** Creating additional features from trip dates, cruise companies, ships, and destinations.
5. **Model Development:** Training regression models to predict cruise prices.
6. **Model Evaluation:** Assessing performance using R², MAE, and RMSE.
7. **Data Visualization:** Presenting project findings through an interactive dashboard and presentation.

## 📌 Key Outcomes

- Developed an end-to-end Machine Learning workflow.
- Identified relevant features for cruise price prediction.
- Achieved a test R² score of 0.9192 with the Random Forest model.
- Presented analytical findings through visualizations and project documentation.
